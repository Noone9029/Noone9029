# Muhammad Ahmad

## Full-stack product engineer building AI, data, and business systems

I build software that connects thoughtful product experiences with reliable backend workflows, useful data, and clear operational outcomes. My work spans accounting SaaS, AI-powered applications, data pipelines, analytics, and production-minded web systems.

Currently, I am building **LedgerByte**, an accounting SaaS foundation for small and growing businesses. It is in controlled beta and user testing, with production hosting, compliance, and provider integrations kept deliberately separate from the current beta scope.

## What I build

- Full-stack web applications and backend APIs
- AI features using RAG, embeddings, semantic search, and LLM APIs
- Data pipelines, ETL workflows, validation systems, and dashboards
- Cloud-backed products with authentication, storage, and serverless workflows
- Responsive interfaces with strong information architecture and practical motion
- Automation and internal tools that make real workflows easier to operate
